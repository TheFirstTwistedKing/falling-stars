# TRPG 디스코드 봇

라시안컷 기반 '추락하는 불빛' 세계관용 디스코드 TRPG 봇입니다. CoC식 d100 백분율 판정을 씁니다.

## 기능

| 분류 | 명령 | 설명 |
|---|---|---|
| 주사위 | `/roll 식` | `2d6+3`, `d100`, `4d6kh3`(높은 3개), `2d20kl1`(낮은 1개) |
| 판정 | `/판정 기능 / 수치` | d100 판정. 대성공(01) · 극단(1/5) · 어려움(1/2) · 성공 · 실패 · 대실패. 보너스·페널티 주사위, 난이도 |
| | `/이성판정 성공손실 실패손실` | 예: `0` / `1d6`. 결과만큼 이성이 자동으로 줄고, 대실패면 최댓값을 잃음 |
| 캐릭터 (관리자) | `/캐릭터 생성·능력치·기능·꾸미기·삭제` | 관리자가 유저를 지정해 캐릭터를 만들고 고침. 능력치는 랜덤(3d6×5 등) 또는 직접 입력 |
| 캐릭터 (플레이어) | `/캐릭터 보기·목록·선택·자원` | 배정받은 캐릭터 중에서 선택. 플레이 중 체력·이성 등 자원 변경 |
| 세션 | `/세션 시작·상태·종료` | 채널 단위. 시작한 사람이 GM. 종료하면 기록을 txt 파일로 내보냄 |
| 전투 | `/전투 추가·제외·시작·다음·종료` | 민첩 순 차례, 라운드 표시 |
| 도감 | `/도감 검색·목록·추가·삭제` | `data/lore.json`(설정집) + 서버에서 GM이 추가한 항목 |
| 상황극 | `/서술` | GM 서술. 타자 효과로 글자가 차례로 드러남. 내용을 비우면 여러 줄 입력창 |
| | `/장면 제목 설명 이미지` | 장면 전환 카드 |
| | `/말하기 대사 행동` | 내 캐릭터의 이름·얼굴로 말하기 |
| | `/npc 등록·대사·목록·삭제` | NPC의 이름·얼굴로 말하기 (타자 효과 선택) |

**관리자**: 서버 관리 권한이 있거나 `GM` 역할(이름은 `.env`의 `GM_ROLE_NAME`으로 바꿀 수 있음)을 가진 사람. 캐릭터는 관리자만 만들 수 있고, 플레이어는 자기에게 배정된 캐릭터만 씁니다.

**GM 권한**(서술·장면·NPC·도감 편집·세션 종료): 관리자, 또는 이 채널에서 세션을 시작한 사람.

명령 옵션에서 줄바꿈을 하려면 `\n`을 쓰거나, `/서술`이나 `/npc 대사`에서 내용을 비워 입력창을 여세요.

## 설치

1. [디스코드 개발자 포털](https://discord.com/developers/applications)에서 앱을 만들고 **Bot** 탭에서 토큰을 받습니다.
2. **OAuth2 > URL Generator**에서 `bot`, `applications.commands`를 고르고, 권한은 아래를 고릅니다. 만들어진 링크로 서버에 초대합니다.
   - 메시지 보내기, 링크 첨부(Embed Links), 파일 첨부, 메시지 기록 보기, **웹후크 관리**(`/말하기`, `/npc 대사`에 필요)
3. 실행합니다.

```bash
pip install -r requirements.txt
cp .env.example .env    # DISCORD_TOKEN 채우기, 테스트 중이면 DEV_GUILD_ID도
python -m bot.main
```

`DEV_GUILD_ID`를 넣으면 그 서버에 명령이 바로 뜹니다. 비우면 전역 등록이라 반영까지 최대 1시간 걸릴 수 있습니다.

세션 중 일반 채팅까지 기록하려면 `.env`에서 `LOG_CHAT=true`로 바꾸고, 개발자 포털 **Bot > Message Content Intent**를 켜세요. 끄면 명령 결과(굴림, 서술, 대사 등)만 기록됩니다.

봇을 24시간 켜 두려면 항상 켜져 있는 컴퓨터나 호스팅(VPS 등)에서 실행해야 합니다.

## 세계관 데이터 넣기

`data/lore.json`은 일부러 비워 두었습니다. 형식은 다음과 같습니다.

```json
{
  "categories": {
    "<분류 이름>": [
      { "name": "<항목 이름>", "body": "<설명>", "tags": ["<검색어>"] }
    ]
  }
}
```

파일을 고치면 재시작 없이 다음 `/도감` 명령부터 반영됩니다. 서버에서 `/도감 추가`로 넣은 항목은 DB에 저장되고, 이름이 같으면 파일 항목보다 우선합니다.

능력치 이름(근력·건강·크기·민첩·외모·지능·정신·교육)과 자원(체력·마력·이성·행운)은 `bot/coc.py`의 `STATS`, `RESOURCES`에 있습니다. 세계관에 맞게 이름을 바꿀 때는 같은 파일의 `derive_resources`(체력·마력·이성 계산식)도 함께 고쳐야 합니다.
